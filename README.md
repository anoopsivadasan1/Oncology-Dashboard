# Oncology-Dashboard
A two‑tab dashboard featuring a spider plot for tumor‑growth, interactive table, and a Kaplan–Meier survival curve.

# Input data
There are two input files used, both in .xlsx format. 
1. tumor_growth_data.xlsx
   This contains a sample dataset containing 10 Subjects with Baseline and Change from
   Baseline tumor measurements recorded at various Visits.
   
2. km_data.xlsx
   This contains a sample dataset containing 10 Subjects their Event (1 if Death, 0 if Alive)
   and Survival time observed is entered
   
Both data are included with one stratification factor - TNF_Status (Tumor Necrosis Factor),
which will be used as selection
